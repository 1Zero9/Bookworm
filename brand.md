# Bookworm — Brand & UI Direction (v2)

## Vision

Bookworm is not just a text editor.

It is a modern creative writing studio designed for:
- long-form writing
- manuscript organisation
- narration scripting
- book creation
- immersive focus writing

The application should feel:
- calm
- premium
- creative
- modern
- approachable
- distraction-free

The experience should support:
- professional writers
- hobbyists
- younger users
- creators experimenting with AI-assisted storytelling

---

# Brand Positioning

## Core Direction

Move away from:
- novelty typewriter simulator
- overly vintage UI

- themed gimmicks

Move toward:

- elegant productivity

# Focus Writing Mode

## Important Feature

Bookworm should include:
### “Focus Writing Mode”

Features:
- fades away interface chrome
- centres text
- optional typewriter sounds
- gentle cursor glow
- warm paper background
- immersive writing experience

This is where the nostalgic typewriter inspiration belongs.

The nostalgia should be:
- optional
- immersive
- feature-driven

Not forced into the entire UI.
