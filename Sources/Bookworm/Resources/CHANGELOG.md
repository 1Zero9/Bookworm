## Version 2.7.37 (Build 40) — May 23, 2026
- Refocused Bookworm around a quiet novel-writing workflow.
- Simplified the launcher to New Novel, Open Book, and recent books.
- Removed the visible template grid, scratch/sandbox card, and production-studio language from the launch experience.
- Removed always-visible Narrate and Publish tabs from the main workspace.
- Removed the permanent playback bar from the writing screen.
- Reduced the main writing toolbar to reading width and focus controls.
- Removed daily-surface AI scene artwork and AI cover generation controls while keeping manual cover selection.
- Updated README positioning to describe Bookworm as a private novel-writing desk.
